## 📖 What is this?

**BeamNG-Earth-Explorer** is an alternative build of the **BeamNG.Earth** project — a massive modification that recreates the entire planet Earth at a **1:1 scale** inside BeamNG.drive.

Instead of switching between static maps, you can now start a drive **anywhere in the world**. The mod uses real LiDAR elevation data, satellite imagery, and OpenStreetMap data to procedurally generate roads, buildings, bridges, and vegetation on the fly. 

You can search for your home city, teleport there, and drive through familiar streets, or set a GPS route to another country. The world streams in real-time as you drive, with a local server handling the data caching and generation.
